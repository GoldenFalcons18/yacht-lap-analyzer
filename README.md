# ヨット周回GPS比較

上下2マークを回るヨット練習のGPXを読み込み、周回全体・指定区間・地図上で選んだ地点を比較するブラウザーアプリです。

公開アプリ: https://goldenfalcons18.github.io/yacht-lap-analyzer/

## 起動

index.html をブラウザーで開きます。インストールやサーバーは不要です。GitHub Pagesに配置して公開できます。

## 使い方

1. 時刻付きGPXを選択します。
2. マーク位置が変わらない練習は上下マークの緯度・経度と通過判定半径を入力します。配置を変更した場合はマーク履歴CSVを読み込みます。
3. 必要に応じてマーク履歴CSVを読み込みます。次に風ログCSVを選択します。風ログは下記の列を使い、1回の観測を1行にします。
4. 周回全体と距離割合で指定した部分区間を同時に確認します。
5. 航跡図をクリックすると、各周回の最寄りGPS点を比較します。

マーク履歴CSVの列名: time, mark_a_latitude, mark_a_longitude, mark_b_latitude, mark_b_longitude。マークを移動した日時と、その時点から次の移動まで有効な上下マークの座標を1行で記録します。列名テンプレートは mark-log-template.csv です。時刻はGPXと同じタイムゾーンを明記してください。履歴CSVの座標が指定時刻以降の判定に使われます。配置変更をまたぐ周回は比較対象にせず、新しい配置で検出した周回から比較します。
風ログCSVの列名と単位:

- time: ISO 8601日時。タイムゾーンを含めてください（例 2026-10-26T09:15:00+09:00）。
- latitude, longitude: 風を観測した場所の緯度・経度（度）。
- wind_from_deg: 風が吹いてくる方角。北0°、東90°、南180°、西270°。
- wind_speed_kn: 風速（ノット）。

CSVの空テンプレートは wind-log-template.csv です。観測時刻と場所が分かる風データを複数記録してください。各GPX点の風向・風速は、初期設定では時刻差12時間以内・距離10km以内の観測だけを使い、時刻と距離が近い観測に大きな重みを付けた推定値です。許容時間差は画面で1〜48時間に変更できます。範囲内に観測がなければ角度・風速は欠測になります。これは観測値そのものではなく、記録された風データからの推定です。

## 表示内容

- 周回時間、距離、平均艇速、前周との差
- 周回の距離割合に沿った艇速と風速のグラフ（ノット）
- 進行方位と、その時刻・位置に対応する風向との差（0〜180°）
- 地図上で選んだ地点における最寄りGPS点の艇速、風速、進行方位、風に対する角度
- 周回ごとに色分けした航跡

GPSの進行方位は位置変化から推定するため、低速時や記録間隔が粗い場合は不正確になります。風・潮、艇種やタックの質の補正は行いません。比較結果は練習の振り返り用の参考値です。GPXと風ログCSVはブラウザー内で処理し、外部へ送信しません。
